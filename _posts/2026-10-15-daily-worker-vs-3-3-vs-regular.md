사람을 쓸 때 "일용직으로 할까, 3.3% 떼고 줄까, 정식 직원으로 뽑을까" 고민하신다면,
세 방식은 **떼는 세금만 다른 것이 아닙니다.**
4대보험, 퇴직금·주휴수당, 매월 신고, 그리고 나중에 문제가 됐을 때의 **소급 부담**까지 달라집니다.
사업주 관점에서 차이를 정리합니다.

## 1. 한눈에 보는 비교

| 구분 | 일용근로자 (근로소득·일용) | 3.3% 사업소득 (프리랜서·인적용역) | 상용근로자 (정규직) |
| --- | --- | --- | --- |
| 소득 구분 | 근로소득(일용) | 사업소득 | 근로소득 |
| 원천징수 | 일급에서 15만원 공제 후 6% × (1−55% 세액공제) = 초과분의 실효 2.7% + 지방소득세 (합계 2.97%) | 지급액의 3% + 지방소득세 0.3% = 3.3% | 매월 근로소득 간이세액표로 원천징수 |
| 정산 | 분리과세로 종결 (연말정산 없음) | 소득자가 다음해 5월 종합소득세 신고로 정산 | 다음해 2월 연말정산 |
| 4대보험 | 고용·산재 의무, 연금·건강은 요건 충족 시 | 원칙 미적용 (본인이 지역가입) | 4대보험 전부 적용 |
| 근로기준법 | 원칙 적용 | 미적용 (독립 사업자) | 전면 적용 |

일용근로자는 계산된 세액이 **1천원 미만이면 징수하지 않습니다** (소액부징수).

## 2. 매월 해야 하는 신고

| 구분 | 신고 내용 |
| --- | --- |
| 일용근로자 | 원천징수이행상황신고 (다음달 10일) / **일용근로소득 지급명세서 매월** (다음달 말일) / 근로복지공단 **근로내용확인신고 다음달 15일** (국세청 항목 기재 시 지급명세서 갈음 가능) |
| 3.3% 사업소득 | 원천징수이행상황신고 (다음달 10일) / **간이지급명세서(거주자 사업소득) 매월** (다음달 말일) 제출 시 연간 지급명세서 면제 |
| 상용근로자 | 원천징수이행상황신고 (매월 또는 반기) / 간이지급명세서(근로) **반기** 제출, **2027.1월 지급분부터 매월** / 4대보험 취득·상실 신고 (14일 이내 등) |

## 3. 4대보험, 누가 가입 대상인가

**일용근로자**

- **고용·산재: 의무** (근로일수 무관)
- **국민연금**: 1개월 이상 근로하면서 월 **8일 이상** 또는 월 **60시간 이상** 일하면 사업장가입 대상 (소득 기준 등 세부 요건은 국민연금공단 안내 확인)
- **건강보험**: 고용기간 1개월 이상 (실무상 월 8일 이상)이면 직장가입

**3.3% 사업소득**

- **원칙 미적용** — 근로자가 아니므로 본인이 지역가입합니다.
- 예외: **노무제공자 산재 특례** (지정 직종, 보험료 사업주·본인 각 1/2), 지정 직종 노무제공자·예술인 고용보험

**상용근로자** — 4대보험 전부 적용. 2026년 사업주 부담분은 다음과 같습니다.

| 보험 | 사업주 부담 (2026) |
| --- | --- |
| 국민연금 | 4.75% |
| 건강보험 | 3.595% |
| 장기요양 | 건보료 × 13.14% (≈0.47%) |
| 고용보험 | 1.15% (150인 미만) |
| 산재보험 | 업종별 (평균 1.47%) |
| **합계** | **약 11.4%** |

## 4. 퇴직금·주휴·연차·해고 (근로기준법)

- **일용근로자** — 근로자이므로 **원칙 적용**. 주 15시간 이상·소정근로일 개근 시 **주휴수당**, 계속근로 **1년 이상**이면 **퇴직금**. 반복 고용 시 연차·해고 제한도 적용될 수 있습니다.
- **3.3% 사업소득** — **미적용** (독립 사업자). 단, **실질이 근로자이면 전부 소급 적용**됩니다.
- **상용근로자** — **전면 적용**: 주휴, 연차, 1년 이상 퇴직금, 해고 제한·예고. 상시 5인 미만은 연차·부당해고 구제 등 일부 미적용.

## 5. 비용 인정과 증빙

| 구분 | 갖춰야 할 증빙 |
| --- | --- |
| 일용근로자 | **지급명세서 제출** + 신분증 사본, 근로계약서·출근부, **계좌이체 내역** (현금 지급 시 수령증) |
| 3.3% 사업소득 | 원천징수·간이지급명세서 제출 + **용역계약서**, 결과물·청구서, 계좌이체 내역 |
| 상용근로자 | 급여대장, 근로계약서, 원천징수·4대보험 신고 내역, 계좌이체 |

## 6. 월 300만원을 줄 때 사업주 추가부담

| 구분 | 사업주 추가부담 |
| --- | --- |
| 일용근로자 (일당 15만원 × 20일 → 소득세 0원) | 고용·산재만: 약 **7.9만원** (2.6%) / 연금·건강 가입요건 충족 시 (월 8일 이상 계속): 약 **34.3만원** (11.4%) / 1년 이상 계속 시 퇴직금 (월 약 25만원) 추가 |
| 3.3% 사업소득 | **약 0원** (산재 특례 직종이면 소액 발생) |
| 상용근로자 | 4대보험 사업주분 약 **34.3만원** + 퇴직급여 적립 (1/12) 약 **25만원** = 합계 약 **59만원/월** (약 19.8%) + 연차수당 등 |

3.3%가 "약 0원"인 이유: 3.3%는 **지급액에서 떼어 대신 납부하는 세금**이지 사업주 비용이 아니기 때문입니다.

> 예시·추정: 비과세 없음, 상시 150인 미만, 산재 평균요율 1.47% 가정.
> 실제는 업종 요율·보수월액·근로일수에 따라 달라집니다.

## 7. 자주 걸리는 함정 5가지

1. **3개월 룰** — 동일 고용주에 **3개월 이상 계속 고용**되면 세법상 상용근로자입니다
   (소득세법 시행령 20조, **건설공사는 1년**).
2. **가짜 3.3%** — 출퇴근·지휘감독·고정급 등 실질이 근로자면
   4대보험·퇴직금이 **소급**되고, 근로감독 위험도 있습니다.
3. **일용직 반복 고용** — 매월 8일 이상 계속 근무하면 연금·건강 가입 대상.
   미신고 시 보험료가 **소급 부과**될 수 있습니다 (징수 소멸시효 3년).
4. **지급명세서 가산세** — 미제출·불분명 시 지급명세서 종류에 따라 지급액의 **0.25%~1%** (기한 후 일정 기간 내 제출 시 감면).
5. **근로장려금·지원금** — 신고가 누락되면 근로자가 근로장려금에서 불이익을 받고,
   비상용 인력은 고용지원금 대상에서도 불리합니다.

## 8. 체크리스트

- [ ] 인력별 근무 기간·일수·지휘감독 여부로 처리 방식을 구분했다
- [ ] 같은 사람을 3개월 이상 계속 쓰고 있다면 상용 전환을 검토했다
- [ ] 일용직 지급명세서·근로내용확인신고를 매월 하고 있다
- [ ] 3.3% 외주자 간이지급명세서를 매월 제출하고 있다
- [ ] 3.3% 외주자 중 출퇴근·지시를 받는 사람이 없는지 확인했다
- [ ] 인건비는 계좌이체로 주고, 계약서·출근 기록·신분증 사본을 보관하고 있다

## 정리

- **계속 근무하는 인력**은 상용으로 4대보험 정상 가입.
- **단기·간헐 인력**은 일용으로 매월 신고.
- **독립 사업자** (자기 책임·재량으로 결과 제공)만 3.3%.

비용을 줄이려고 형식만 바꾸면 **소급 부담이 더 클 수 있습니다.**
